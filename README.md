# Art by Matt Hollis Website

Custom mobile-first artist website for Matt Hollis, replacing the existing WordPress site at `artbymatthollis.com`.

## Project Vision

A portrait-oriented, mobile-first website that functions as:

- Artist calling card
- Illustrated professional brochure
- Selected works gallery
- News and exhibition feed
- Thirty-year visual timeline
- Studio profile
- Contact point

The design should appear handmade, organic, colorful, and expressive, while behaving like a highly polished modern web application.

## Technology Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- PhotoSwipe
- Optional Framer Motion
- File-based content (TypeScript/MDX)
- Vercel
- Cloudflare
