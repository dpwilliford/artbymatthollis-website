# Image System

All images should be tappable and open in PhotoSwipe.

Features:

- Full-screen viewing
- Swipe navigation
- Pinch-to-zoom
- Captions
- Alt text
- Multiple views per artwork
- Lazy loading
- Web-optimized formats

Optional future enhancements:

- 360-degree rotation
- OpenSeadragon deep zoom
- IIIF compatibility
